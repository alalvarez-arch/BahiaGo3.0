# BahiaGo 2.0

PWA de turnos y equipo para hosteleria de lujo.

## GitHub Pages

1. Sube a la **raiz** del repositorio: `index.html`, `manifest.webmanifest`, `manifest.json`, `sw.js`, `.nojekyll`, carpeta `icons/`.
2. Settings → Pages → branch `main` → folder `/ (root)`.
3. URL: `https://USUARIO.github.io/REPO/`

Si no puedes subir `.nojekyll` (archivo oculto), crealo vacio en el repo con **Create new file**.

## Instalar

- **Android (Chrome):** Instalar aplicacion
- **iPhone (Safari):** Compartir → Anadir a pantalla de inicio
